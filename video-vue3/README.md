## 需求背景

```
用 vue3 技术栈开发一款AI学英语软件, 不要用ts, 只需要用js开发即可
需要完善的前后端功能, 但注意你需要使用 NextJs 数据库可以使用 sqlite
具体玩法如下:

页面分为左右两边, 左边是视频 两边各占一半(这是个在 Ipad 上的应用), 右边是笔记本
左边视频区域:等比例展示视频, 充满, 黑色背景, 点击任意地方都可以暂停视频, 视频一进来就是播放状态, 并且是循环播放, 有一些简单的设置区域: 隐藏字幕,
视频区域具体功能:
    - 点击暂停, 按下拖动可以快进/快退
    - 工具区域: 隐藏/打开字幕按钮 (工具区域位于视频的右侧居中)

右边是笔记本区域: 这里用户可以输入自己学到的英文, 也可以输入语音(录音功能最长60秒)
输入的语音和在笔记本中独占一行, 标记出语音的市场, 点击可以播放/暂停播放

这个笔记本可以用一些轻量化的开源软件

```

## 开发要求

你要先进行数据库设计, 然后是接口设计, 之后是页面布局, 最后在联调接口. 按照这个步骤进行开发.

## 代码规范

    1. 用 vue3 配套的工具
    4. 注意代码尽量简洁, 注释要简练, 注意代码的可维护性
    5. 所有的场景都要考虑国内环境, 比如 cnpm 之类的
