# 看视频学英语

一个帮助用户通过视频学习英语的应用程序。

## 功能特点

- 视频上传与管理
- AI 智能字幕识别
- 视频播放控制（快进/倒退/暂停）
- 字幕笔记功能
- 语音输入支持
- 响应式布局，适配 iPad

## 技术栈

- Vue 3
- Nuxt 3
- Pinia（状态管理）
- Sass（样式）

## 安装步骤

```bash
# 使用 cnpm 安装依赖（国内环境推荐）
cnpm install

# 或使用 npm
npm install

# 启动开发服务器
npm run dev
```

## 使用说明

1. 点击「添加视频」按钮上传视频文件
2. 系统会自动识别视频中的英文字幕
3. 选择任意字幕可跳转到对应时间点
4. 在下方输入框添加学习笔记
5. 支持语音输入功能
